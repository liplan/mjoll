En resumen

Mjoll no recopila, almacena ni comparte datos personales. No hay cuentas, ni análisis, ni publicidad, ni rastreo. La app funciona por completo en tu iPhone y no se conecta a ningún servidor.

Datos en la app

La app solo guarda tus ajustes de forma local en tu dispositivo: si viste la introducción y confirmaste las indicaciones de seguridad, y la velocidad que elegiste para cada programa. Esta información nunca sale de tu iPhone. Al eliminar la app, se borra.

Compras

Apple gestiona todas las compras a través del App Store. No recibimos tus datos de pago. Se aplica la política de privacidad de Apple: apple.com/mx/legal/privacy.

Este sitio web

Este sitio web está alojado en GitHub Pages (GitHub Inc., EE. UU.). Al visitarlo, GitHub procesa datos técnicos como tu dirección IP para entregar la página y mantenerla segura. La base legal es nuestro interés legítimo en ofrecer un sitio web (art. 6, apdo. 1, letra f del RGPD). Consulta la declaración de privacidad de GitHub. Este sitio no usa cookies ni rastreo. Si eliges la vista clara u oscura o un idioma, solo tu navegador guarda esa elección. La lectura en voz alta usa la voz de tu propio dispositivo; no se envía nada.

Contacto

Si nos escribes, usamos tu mensaje solo para responderte y lo borramos cuando ya no es necesario.

Tus derechos

Tienes derecho de acceso, rectificación, supresión, limitación del tratamiento, portabilidad y oposición (arts. 15–21 del RGPD). También puedes presentar una reclamación ante una autoridad de protección de datos, por ejemplo la Landesbeauftragte für Datenschutz und Informationsfreiheit Nordrhein-Westfalen.
