Achtsamkeit ohne Leistungsdruck: Warum Mjoll keine Streaks zählt

Muss eine Meditationspause gezählt werden, damit sie zählt?

Mjoll zählt keine Streaks und beobachtet nicht, wie oft du übst. Dahinter steht eine Haltung: Achtsamkeit braucht keine lückenlose Erfolgsserie. Das ist eine bewusste Entscheidung bei der Gestaltung, kein wissenschaftlicher Beweis dafür, dass Zähler grundsätzlich schlecht sind.

Wenn aus einer Pause eine Serie wird

Ein Streak zeigt, wie oft du eine Handlung an aufeinanderfolgenden Tagen ausgeführt hast. Solche Serien können motivieren. Vielleicht gefällt dir das sichtbare Zeichen, dass etwas einen Platz in deinem Alltag gefunden hat.

Es kann aber auch eine andere Frage entstehen: Öffne ich die App gerade für eine Pause oder damit die Reihe nicht abreißt? Diese Frage wertet keine Form der Motivation ab. Sie macht lediglich sichtbar, dass die Darstellung einer Übung zum eigenen Ziel werden kann.

Mjoll verzichtet darauf, um dieser zusätzlichen Aufgabe keinen Raum zu geben. Ein ausgelassener Tag braucht dann keine Erklärung gegenüber einem Zähler. Ob Menschen das tatsächlich als weniger Druck erleben, müsste gesondert untersucht werden.

Was sagt die Forschung?

Silverman und Barasch untersuchten in sieben Studien, wie dargestellte Verhaltensserien spätere Entscheidungen beeinflussen. Intakte und unterbrochene Serien wirkten unterschiedlich auf die Bereitschaft, eine Handlung fortzusetzen. Entscheidend konnte bereits die Darstellung sein, auch bei gleichem vorherigem Verhalten. Die Untersuchungen betrafen etwa Bewegung, Lernen und Spiele.1

Das ist ein Hinweis auf die Bedeutung von Gestaltungsentscheidungen. Es ist kein Nachweis dafür, dass Streaks Meditation verschlechtern oder psychisch schaden. Ebenso wenig beweist es, dass eine App ohne Spielmechaniken die bessere Praxis ermöglicht.

Datenschutz ist eine eigene Frage

Ein fehlender Zähler sagt noch nichts darüber aus, welche Daten eine App verarbeitet. Eine Anwendung könnte keine Statistik zeigen und trotzdem Nutzungsdaten übertragen. Umgekehrt können Einstellungen lokal gespeichert werden, ohne dass daraus eine Überwachung entsteht.

Mjoll arbeitet auf deinem iPhone ohne Konten, Analyse, Werbung, Tracking oder Serververbindung. Deine Einstellungen bleiben auf dem Gerät, ebenso die Bestätigung der Sicherheitshinweise. Die Einzelheiten stehen in der Datenschutzerklärung.

App und Website sind dabei zu unterscheiden. Beim Aufruf dieser Website verarbeitet der Hosting-Anbieter GitHub technische Daten wie die IP-Adresse; Käufe wickelt Apple ab. Eine lokal gespeicherte Einstellung ist außerdem etwas anderes als eine übertragene Nutzungsstatistik. Diese Unterschiede machen Datenschutz verständlicher als ein pauschales „keinerlei Daten“.

Regelmäßigkeit ohne Verpflichtung

Du kannst einen vertrauten Zeitpunkt mögen und trotzdem keine Serie führen wollen. Wiederholung und Leistungsbewertung sind unterschiedliche Dinge. Eine Pause darf wiederkehren, ohne Teil einer persönlichen Statistik zu werden.

Ob du eine Pause heute brauchst, lässt sich nicht aus einer Zahlenreihe ablesen. Der Rahmen kann verlässlich sein und dir trotzdem die Entscheidung lassen, ihn an einem bestimmten Tag nicht zu nutzen.

Der Gedanke hinter Mjoll bleibt überschaubar: Du darfst eine Übung beginnen und wieder beenden. Sie muss keine Zahl verbessern. Vielleicht ist gerade das die Form von Freiraum, die du suchst.
